# План обновления «Красных линий»

## Что изменится
- Заменить раздел «GitHub / uCoz» на «СМИ» в шапке, меню и пользовательских страницах.
- Добавить новый маршрут `/smi` с редакционной лентой СМИ и фильтрами: «Новость», «Анализ», «Интервью», «Фактчек», «Академия».
- Добавить отдельные страницы материалов СМИ по адресам `/smi/$slug`.
- Оставить старый адрес `/zerkala` как совместимый переход на `/smi`, чтобы старые ссылки не ломались.
- Обновить материалы блоков II–IV по предоставленному списку из 8 источников с нейтральными формулировками.

## Контент
- Создать локальную структуру данных для раздела СМИ: издание, дата, заголовок, тип, краткий пересказ, оригинальная ссылка, блоки «Что пишет источник», «Контекст», «Ограничения и спорные моменты».
- Добавить минимум 8 карточек СМИ: 6 из списка пользователя плюс Financial Times и AP.
- Для спорных тезисов использовать атрибуцию: «по версии автора», «в интервью он заявил», «позиция правительства КНР», без оценок «кто прав/виноват».
- В блоках II–IV заменить/пересобрать набор материалов так, чтобы они соответствовали указанным источникам и нейтральным ограничениям.

## Визуал
- Сохранить текущий тёмный архивный стиль, золотисто-бронзовые линии, serif-заголовки и карточную сетку.
- Для `/smi` сделать плотную редакционную ленту с крупной датой, названием издания, аннотацией, фильтрами и ссылками «Оригинал» / «Подробнее».
- Проверить мобильную раскладку без горизонтального переполнения.

## Технический контроль
- Обновить метаданные страниц: `/smi`, `/smi/$slug`, `/zerkala`, а также проверить существующие маршруты.

## Технические детали
- Проект останется без базы данных, авторизации и серверного хранения.
- Данные будут локальными TypeScript-структурами.
- Маршрутизация останется на текущем механизме проекта, чтобы не ломать live preview Lovable.
